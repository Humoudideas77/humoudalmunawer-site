Founder Agent Skills OS

Problem
Agent sessions fail founders when tip-spam replaces a thin constitution and clear jobs.
Built
Personal operator pack: thin AGENTS.md plus five founder skills — research, decide, scan rivals, stress a spec, close the day.
Result
Drop-in markdown for Claude Code, Cursor, Codex and similar — no vendor lock-in, no marketplace required.
Learning
Operators need jobs with kill criteria more than another “invent an OS” prompt.

Model Routing Calculator

Problem
Teams default every task to the top-tier model and overpay for judgment that does not need it.
Built
A dependency-free Python CLI (`route.py`) that recommends model tier by complexity and estimates cost vs. always-top-tier.
Result
Example outputs: ~63% of baseline for judgment-heavy work; ~46% for long-unattended tasks.
Learning
Routing is a product decision, not a model beauty contest — measure before you standardize.
