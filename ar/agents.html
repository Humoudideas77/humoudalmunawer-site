ملاحظة مؤسّس

ملف تعليمات واحد لكل وكلاء البرمجة: AGENTS.md وCLAUDE.md

أصبح Claude Code يقرأ AGENTS.md، لكن فقط حين لا يوجد CLAUDE.md في طريقه. إعداد قصير يُبقي كل وكلاء البرمجة على التعليمات نفسها.

المستودع الذي يعمل فيه أكثر من وكيل برمجة يميل إلى جمع ملف تعليمات لكل مزوّد: CLAUDE.md، وقواعد Cursor، وتعليمات Copilot، وGEMINI.md. يبدأ كل ملف نسخةً من غيره، وبعد أسابيع قليلة تتعارض الملفات، ولا يعرف أحد أيّها المرجع.

‏AGENTS.md هو الحل المفتوح لهذه المشكلة: ملف Markdown واحد بسيط في جذر المستودع، يقرؤه OpenAI Codex وCursor ووكيل البرمجة في GitHub Copilot وأدوات كثيرة غيرها، وتتولّى رعايته اليوم مؤسسة Agentic AI Foundation التابعة لمؤسسة Linux. ومنذ الإصدار 2.1.277 الصادر في 18 سبتمبر 2026، صار Claude Code يقرؤه أيضًا.

ما الذي تغيّر في Claude Code

في أي مشروع لا يحتوي على CLAUDE.md، يقرأ Claude Code الآن AGENTS.md بدلًا منه. ويُضبط هذا السلوك من إعداد Project instructions داخل /config.

كان في الإصدار الأول نقص: الجلسات العاملة على Amazon Bedrock وGoogle Vertex AI وMicrosoft Foundry، والجلسات التي عُطّل فيها القياس عن بُعد، ظلّت تقرأ CLAUDE.md فقط. ثم سدّ الإصدار 2.1.281 (23 سبتمبر 2026) هذا النقص، وشمل كذلك بوابات النماذج اللغوية. إن كان فريقك يشغّل Claude Code عبر مزوّد سحابي، فالحل هو التحديث لا الانتظار.

المفاجأة: CLAUDE.md ما زال يتقدّم افتراضيًا

افتراضيًا، لا يقرأ Claude Code ملف AGENTS.md إلا إذا لم يوجد CLAUDE.md أو .claude/CLAUDE.md أو CLAUDE.local.md في مجلد العمل أو أي مجلد أعلى منه. فإذا أبقيت CLAUDE.md «للاستثناءات فقط» دون ربطه، تجاهل Claude الملف المشترك بصمت. والملف الشخصي CLAUDE.local.md له الأثر نفسه.

هناك إعدادان يحافظان على مصدر واحد للحقيقة:

  1. ضع @AGENTS.md في السطر الأول من CLAUDE.md، وأضف تحته التعليمات الخاصة بـ Claude وحده. يقرأ Claude الملف المشترك أولًا ثم الباقي، ولا يحمّل الملف نفسه مرتين.
  2. أو اضبط Project instructions على القيمة claude-md-and-agents-md داخل /config، فيُحمَّل الملفان معًا.

إن لم يكن في CLAUDE.md شيء خاص بـ Claude، فاحذفه. والرابط الرمزي إلى AGENTS.md يؤدي الغرض أيضًا، لكن تجنّبه إن كان أحد يستنسخ المستودع على Windows.

ثلاث خطوات تحقّق تكفي

  1. شغّل claude --version. تحتاج إلى الإصدار 2.1.277 أو أحدث، وإلى 2.1.281 أو أحدث على Bedrock أو Vertex AI أو Foundry أو عبر بوابة أو مع تعطيل القياس عن بُعد.
  2. شغّل /memory وتأكّد من ظهور مسار AGENTS.md في القائمة.
  3. إن وُجد أي CLAUDE.md على مسار المشروع، فتأكّد من أنه يستورد @AGENTS.md.

رأي حمود

اجعل AGENTS.md الملف الجذري. وتعامل مع CLAUDE.md كطبقة رفيعة: سطر استيراد واحد، ثم القواعد القليلة التي يحتاجها Claude وحده، مثل الخطافات أو عادات وضع التخطيط. القواعد المكرّرة بين الملفات هي بداية التباعد، فاحذف النسخ بدل محاولة مزامنتها.

افعل هذا الأسبوع

  1. افتح مستودعك الرئيسي واحصر كل ملفات التعليمات: AGENTS.md وCLAUDE.md وCLAUDE.local.md و.cursor/rules و.github/copilot-instructions.md وGEMINI.md.
  2. ادمج القواعد المشتركة في ملف AGENTS.md واحد في الجذر.
  3. اختصر CLAUDE.md إلى @AGENTS.md مع السطور الخاصة بـ Claude، أو احذفه.
  4. أضف سطرًا واحدًا إلى README يحدّد AGENTS.md مصدرًا وحيدًا للتعليمات.

الحدود

هذه نظافة تنظيمية، وليست وعدًا بأن كل وكيل يقرأ AGENTS.md بالطريقة نفسها. فالأولوية تختلف من أداة إلى أخرى: يقرأ Codex أيضًا AGENTS.override.md الذي يتجاهله Claude Code، ويقدّم Cursor وCopilot أقرب ملف AGENTS.md متداخل، ويقرأ Gemini CLI ملف GEMINI.md ما لم تُضف AGENTS.md إلى إعداد context.fileName. تحقّق من الأدوات التي تستخدمها فعلًا.

المصادر

سجل تغييرات Claude Code (الإصداران 2.1.277 و2.1.281) وتوثيق الذاكرة؛ agents.md؛ دليل AGENTS.md في OpenAI Codex؛ توثيق القواعد في Cursor؛ تعليمات المستودع في GitHub Copilot؛ ملفات السياق في Gemini CLI. رُوجعت في 6 أكتوبر 2026.
